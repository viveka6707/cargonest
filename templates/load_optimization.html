How the optimizer works
  1. Checks total package weight against the selected container's rated capacity.
  2. Sorts packages from heaviest to lightest.
  3. Places each next package in the currently lightest of four zones.
  4. Displays zone weights, package assignments and remaining payload.
  5. Saves the generated plan in MySQL for review.
